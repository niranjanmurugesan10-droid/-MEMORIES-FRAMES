# Memories Frames — Frontend Demo

A responsive React + Vite storefront and functional demo admin dashboard.

## Run locally
1. Install Node.js (LTS recommended).
2. Extract the ZIP.
3. Open this folder in VS Code.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Included
- Customer storefront, category browsing, product details, cart
- Custom order form with multiple image uploads and optional voice recording
- LocalStorage-backed demo requests and cart
- Admin dashboard to review submitted requests, preview uploads, play voice notes, update statuses and open a pre-filled WhatsApp message
- Bulk enquiry form
- Responsive desktop/mobile layouts

## Demo limitations
- No backend, database, authentication, real payment gateway, AI/chatbot or courier tracking.
- LocalStorage works only in the same browser profile/device. The admin demo must be opened in the same browser where the request was submitted.
- Browser storage is limited. Keep uploads small; use sample images during demonstrations.
- WhatsApp opens a pre-filled message; the admin must review and press Send.
- Product images are illustrative remote images and should be replaced with the client's actual product photos before presenting the final demo.
- Prices are sample display prices; verify every product/size price with the client before publishing.
- Voice recording requires microphone permission and a supported browser (Chrome recommended).
